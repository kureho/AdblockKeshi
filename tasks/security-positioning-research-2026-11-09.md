### 4-3. 足せる機能（Q3）
- Safari には標準で「詐欺 Web サイトの警告」がある（Google の判定）＝Safari の中だけの詐欺対策は標準と重なる。差が出るのは Safari の外（LINE・メール等のアプリ内ブラウザ、SMS）
- 今の DNS（NEPacketTunnelProvider）に詐欺ドメインの一覧を足すのが一番安い（NEDNSProxyProvider は管理端末だけ。NEDNSSettingsManager は向かない）
- 共有メニューで「開く前にリンクを確かめる」は同じ作りのアプリが既にある（MetaCert 等）
- SMS フィルタは作れるが、iOS 26 の「不明な差出人をスクリーニング」と重なり、日本での細かい分類と安定性が不明
- 一覧の出どころ: URLhaus（CC0・マルウェア中心）・Phishing.Database（MIT）。Google Safe Browsing は非商用のみ。商用の Web Risk API は URL 照会が月 10 万回まで無料だが **Google Cloud の請求先が要る＝新しい有料サービス（kureho の承認が要る）**。フィッシング対策協議会の URL 提供は法人向け
- 審査: 「ウイルス対策」を名乗らない（2.3.1(a)）。実際にやっていること（既知の詐欺サイトの一覧と照合して止める）だけを書く。5.4（VPN は組織の開発者）は、今の DNS が 4.0〜4.4.3 で審査を通っている事実があるので、新しい障害ではない

### 4-4. 手元で測った事実（2026-11-09・`docs/cdn/security-rules.json`・2026-11-01 生成）
- 詐欺サイトの規則 30,000 件のうち、**数字で始まるドメインが 29,602 件、英字で始まるドメインは 398 件**（a〜z 合計）
- 原因（コードで確認）: `scripts/build_security_rules.py` の `build_security_rules()` は URLhaus → Phishing.Database の**元の並び順のまま**入れて 30,000 件で打ち切る。Phishing.Database の一覧は名前順に並んでいるとみられ（出力の偏りからの推定・元の一覧は未取得）、数字で始まる物で枠が埋まる（最後の 1 件は `82491.columbiauniversityinpictures.com`）
- 元の一覧（Phishing.Database ACTIVE・2026-11-09 取得）は 392,178 件で、先頭が `000…`・末尾が `zz…`＝ほぼ名前順。今の一覧はその先頭の約 7.6% だけ。元の一覧には `amazon` を含む物 3,694 件・`rakuten` 482・`aeon` 151・`nta-` 90・`paypay` 79・`saison` 56 などがあるが、今の一覧に `amazon` を含む物は約 120 件
- 利用者に届いている物も同じ偏り: 配信中の 2 本目（報告反映）`docs/cdn/second-ads-sec.json` の末尾 30,000 件＝この一覧そのまま／アプリ同梱の `Extension/Resources/security-rules.json` も数字始まりが 29,621/30,000。基本保護（`merged-rules.json`）には詐欺の規則はほぼ入っていない（A-88 の設計どおり）
- 結果: `amazon-…`・`smbc-…` のような英字で始まる詐欺ドメインのほとんどは今の Safari の詐欺サイト対策に入っていない。**看板に「詐欺サイト」を出す前に、一覧の選び方を直す必要がある**（新しい物・日本向けを優先する等）。配信は GitHub Pages 経由で旧版の利用者にもすぐ届くので、直す時は計測と kureho の承認を経る

## 6. Devil's Advocate（H2 への反論）
- 「Safari の外のリンク」を止めるには VPN 型の構成をオンにしてもらう必要があり、iPhone に「VPN」の表示と許可の画面が出る。慣れた人でも不安を感じる可能性があり、不安な人向けの機能としては入口の摩擦が大きい
- 無料の一覧（世界向け）が、日本の偽宅配・偽銀行・偽 EC の新しいドメインをどれだけ拾えるかは測れていない。詐欺サイトは寿命が短く、一覧は遅れる。拾えなければ「止める」と言える根拠が弱い（拾う力を上げる Web Risk は新しい有料サービス）
- 一番近い 280blocker は東証上場のセキュリティ企業で、同じ「広告ブロック＋詐欺対策」を既に出している。個人アプリの「買い切り」は価格では勝つが、信頼では負ける
- フィッシング報告は 2026 年 2 月に急減した（4 月に戻ったが 2025 年の月 20 万件超には届いていない）。「今が最大のチャンス」とは言い切れない
→ どれも H2 を倒すほどではないが、①一覧の拾う力の測定 ②VPN 構成の摩擦への説明、の 2 つは設計で必ず扱う
