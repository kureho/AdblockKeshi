## 3. 作る物

### 3-1 流れ

報告（アプリ・今のまま）→ 週 1 回の見直しで確かめる（3-2）→ 公開の置き場 `review/scam-domains/` にドメインだけ書いて push → 詐欺サイトの一覧を作り直す（その push でも動く）→ 2 本目の末尾に載って全員に届く。報告者には今の「反映しました」が返る。

**自動の早道は作らない。** 一覧に入る道は、見直しで人が書いたファイルだけ。報告が何件来ても、それだけでは載らない。

### 3-2 確かめ方（載せる基準）

載せるのは、A と B の**両方**を満たす時だけ。

- **A. 今の除外を通る（作り直しの時に自動）**: 人気サイト（Tranco 上位 100 万）とその中・重要ドメイン・公的機関の .jp・共有ホストの親は載らない。報告の物だけ特別に通す道は作らない
- **B. 報告のほかに、独立した根拠が 1 つ以上ある（見直しで確かめる）**
  1. HaGeZi の全部の一覧に既にある（3 万件の枠に入っていないだけ）
  2. ドメインが実在のブランドの名前を含み、そのブランドの公式のドメインでなく、登録から 90 日以内（登録日は RDAP で確かめる）

- 報告の**数**では決めない（1 人が何度も送れる）
- 根拠が報告だけなら載せない（判定は「再現しない」）
- **報告されたページは開かない。** 詐欺の種類の報告は、束でページを開かず、ドメインの事実（B の 1・2）だけを並べる。開くと、相手に見に来た事が伝わり、悪い仕掛けにも触れ得る
- JPCERT/CC の一覧は根拠に使わない（利用の条件が書かれていない。調査 §4 のとおり、遅れて公開されるので確かめにも間に合わない）

### 3-3 置き場の形（公開の repo）

`review/scam-domains/<日付>.json`

```json
{ "added_at": "2026-11-16", "domains": ["example-scam.top"] }
```

- 書くのは**ドメインだけ**。報告の URL のパス・クエリ・メモ・報告の ID・根拠のメモは書かない（根拠は手元の束にだけ残す）
- 形の崩れたファイルが 1 つでもあると作り直しは止まり、前の一覧のまま（今の `review/rules/` と同じ考え方）。崩れは週次の前に手元の試験でも見つける

### 3-4 一覧への入れ方

- 段の順: **報告で確かめた物** → 日本向け → 海外ブランド → その他
- 上限 **500 件**（3 万件の 1.7%）。超えたら新しい物から残す。報告は週に多くて 23 件なので、当分は届かない
- 期限: 追加から **90 日**で自動で外れる（詐欺サイトは短命。間違いを長く残さない）。まだ生きていれば HaGeZi か、もう一度の報告で戻る
- HaGeZi の見出し（NOTICE）は今のまま。報告の物はこちらの判断で、HaGeZi の一覧の改変ではない

### 3-5 報告者への返し

- 判定の値は今の「applied（反映した）」をそのまま使い、新しい値は足さない
- 理由: 新しい値を足すと、報告者へ結果を返す API（Cloudflare Workers）を直して本番に出し直す事になる。applied なら API もアプリもそのままで「反映しました」と出る
- 失う物: DB の上で「詐欺の一覧に載せた」と「サイトの中の規則を足した」を分けられない。分けたい時は、`review/scam-domains/` のファイルと報告の種類から数える

### 3-6 悪意の報告への備え

| 狙い | 備え |
|---|---|
| 競合や気に入らないサイトを止めさせる | 人気サイト 100 万の中は載らない（自動）。100 万の外の小さな正規のサイトは、B の根拠（HaGeZi にある、かブランドの偽装＋新しい登録）が無いと載らない |
| 大量の報告で押し込む | 数で決めない。自動の早道が無い |
| 銀行・役所などを止めさせる | 重要ドメインと公的機関の .jp は除外で載らない |
| 間違って載った | 利用者は「このサイトで一時オフ」で自分で外せる（実機は未確認）。サイトの持ち主からはお問い合わせで受け、ファイルから外せば次の作り直しで消える。90 日で自動で消える |
| 公開の置き場にドメインが載る事そのもの | 「このドメインは詐欺」と公に書く事になる。HaGeZi なども同じ形で公開しているが、こちらの判断の責任はこちらにある。B の基準・期限・外し方で抑える |

### 3-7 届くまでの時間（正直な限界）

- 報告 → 次の見直し（週 1 回）→ push → 数分で作り直し（`review/scam-domains/` への push でも週次の作り直しが動くようにする。日曜の定期と重ならないよう、同時に 1 つだけ動く）
- 報告から届くまで最長で約 1 週間。数日で消える詐欺サイトには間に合わない事が多い。報告で止められるのは、長く生きる物が中心になる
