# DNS 型アプリ内広告ブロックの curated ソースドメイン（v0・2026-07-15）
#
# 形式: 1 行 1 ドメイン。`#` 始まりはコメント。空行は無視。
# DNSBlocklist はラベル境界のサフィックス一致なので、apex を書けばサブドメインも全て一致する。
# apex が広告専用のものは apex を、他用途と混在する親（unity3d.com 等）は広告サブドメインのみを列挙。
#
# ★重要★ critical 保護下（google.com / facebook.com / amazon.com / yahoo.co.jp 等）の
#   apex は DNSCriticalGuard が forward を強制するため、ここに書いても死票になる。
#   よって adservice.google.com / an.facebook.com 等は「DNS では抑止不可」= 除外している。
#
# ★v0 の位置づけ★ 公知の広告配信エンドポイント知識ベースの初版。
#   自作 AdMob アプリでの実測（Task 10.5 の本来の方法）で追補・是正する前提。
#   計測/解析専用（app-measurement.com 等）は「アプリが壊れた」誤解レビュー回避のため v0 では除外。
