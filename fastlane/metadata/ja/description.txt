Safariの広告を、シンプルに消すアプリです。
設定は1分。あとは、もう開かなくて大丈夫。

——
こんな方におすすめ
——
・Safariで全画面広告に何度も誤タップしてしまう方
・既存のアドブロックアプリの設定UIが複雑で、結局使いこなせなかった方
・ご家族（親・子・祖父母）の iPhone にも入れてあげたい方
・サブスクではなく買い切りで広告を消したい方
・個人情報や閲覧履歴を外部に送りたくない方

——
特徴
——
・シンプル極限。アプリ内に設定画面はありません
・iOS の Safari Content Blocker で動くため、別のブラウザを入れる必要なし
・EasyList・EasyPrivacy・AdGuard の公式フィルタを統合し、Safari の上限である 150,000 ルールいっぱいまで使用
・フィルタは月次でバックグラウンド自動更新。アプリを開く必要はありません
・買い切り。サブスクなし。アプリ内課金なし。広告SDKも使用していません
・閲覧履歴・タブ情報を一切読み取りません（iOSの仕様上、技術的に不可能）

——
使い方（所要時間 1 分）
——
1. アプリを起動して「準備する」をタップ
2. iPhoneの設定アプリで Safari → 機能拡張 →「広告消し」をON
3. アプリに戻ると「広告ブロック中」と表示されます
4. あとはSafariを普通に使うだけ。以降このアプリを開く必要はありません

——
ブロックできるもの・できないもの
——
ブロックできる: Safariで表示されるWeb広告（バナー・全画面・ポップアップ）、追跡トラッカー
ブロックできない: Twitter / YouTube / LINE 等のアプリ内広告（Safari ではないため）、Chrome / Firefox 等の他ブラウザの広告

——
使用フィルタ（オープンソース）
——
・EasyList (CC-BY-SA-3.0)
・EasyPrivacy (CC-BY-SA-3.0)
・AdGuard Base Filter (GPL-3.0)
・AdGuard Japanese Filter (GPL-3.0)

フィルタは GitHub Actions で月次自動変換し、CDN（GitHub Pages）配信。BGTaskSchedulerで端末側もバックグラウンド更新します。
