# review/scam-domains/ — 報告を見直しで確かめた詐欺サイト

A-218「報告を詐欺サイトの一覧につなぐ」（設計 `tasks/a218-report-to-scam-list-design-2026-11-09.md`）。
利用者が「詐欺サイト」として報告したサイトを、週 1 回の見直しで確かめてから、ここにドメインだけ書く。
`review/scam-domains/*.json` への push（と毎週日曜の定期実行）で `.github/workflows/build-security-rules.yml` が動き、
`scripts/build_security_rules.py --reported-dir review/scam-domains` が、詐欺サイトの一覧（2 本目の末尾）の
**先頭**に載せる。アプリの更新なしで全員に届く。

## ファイル形式

1 ファイル = 1 回の見直し。ファイル名は自由（例: `2026-11-16.json`）。

```json
{ "added_at": "2026-11-16", "domains": ["example-scam.top"] }
```

- 項目は `added_at` と `domains` の **2 つだけ**。ほかの項目（メモ・URL・報告の ID など）が 1 つでもあると、
  **作り直しごと止まる**（配信は前の版のまま）
- `added_at`: `YYYY-MM-DD`（日本の日付でよい）。ここから **90 日で自動で外れる**。まだ生きていれば、HaGeZi か
  もう一度の報告で戻る
- `domains`: 小文字のドメインだけ（スキーム・パス・`*` は書けない）。そのドメインと、その下のサブドメインが止まる
- 全部で **500 件**まで（新しい日付から数える）

## 載せる基準（設計 §3-2）

次の A と B の両方を満たす時だけ書く。

- **A. 今の除外を通る**（作り直しの時に自動）: 人気サイト（Tranco 上位 100 万）そのものとその上・上位 10 万のサイトの
  中・重要ドメインとその中・公的機関の .jp・共有ホストの親は、ここに書いても載らない。10 万〜100 万位のサイトの中は
  自動では外れないので B で確かめる
- **B. 報告のほかに、独立した根拠が 1 つ以上ある**
  1. HaGeZi の全部の一覧に既にある（3 万件の枠に入っていないだけ）
  2. ドメインが実在のブランドの名前を含み、そのブランドの公式のドメインでなく、登録から 90 日以内

- 報告の**数**では決めない。根拠が報告だけなら書かない（判定は `not_reproduced`）
- 見直しの最初に、配信中の 3 万件に既にあるかを見る。既にあれば書かない（保護を切っている・「このサイトで一時オフ」・
  アプリの不具合のどれか）
- **報告されたページは開かない**（判定用の束も、詐欺の種類の報告はページを開かずにドメインの事実だけを並べる）

### 判定（`review/results/`）は、一覧に載ったのを確かめてから書く

`applied` を書くと報告者に「反映しました」と返る。作り直しが失敗した時や、除外（A）で外れた時にも返ってしまわないよう、
次の順にする（`review/results/` は別のワークフローで、作り直しの成否を見ずに D1 へ書くため）。

1. `review/scam-domains/<日付>.json` **だけ**を push する（同じ push に `review/results/` を入れない）
2. 作り直しのワークフロー（Weekly Security Rules Update）が成功し、main の `docs/cdn/security-rules.json` に
   そのドメインが入ったのを確かめる
3. 載った物は `applied`、載らなかった物（除外で外れた等）は `not_reproduced` で `review/results/` に書いて push する

★**このリポジトリは公開**。書いてよいのは**ドメイン**と**日付**だけ。報告された URL のパス・クエリ・メモ・
根拠のメモは書かない（根拠は手元の判定用の束 `.review-packets/` にだけ残す）。

## 外す時

サイトの持ち主からお問い合わせで申し立てがあり、間違いと分かった時は、そのドメインをファイルから消して push する。
最後の 1 件なら `"domains": []` にしても、ファイルごと消してもよい（どちらでも作り直しは止まらない）。
次の作り直し（push で動く）で一覧から消える。利用者は「このサイトで一時オフ」で自分で外せる。

ファイルはリンク（シンボリックリンク）にしない。同じ項目を 2 回書かない（どちらも作り直しが止まる）。
